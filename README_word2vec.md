# 다중 파일 Word2Vec GUI 사용법

`word2vec_GUI_다중파일_문맥유사어_개선버전.py`는 여러 개의 한국어 뉴스 TXT 파일을 하나로 합쳐 Word2Vec을 학습하고, 기준 키워드와 **문맥상 쓰임이 비슷한 단어**를 엑셀로 저장하는 GUI 프로그램입니다.

기준어가 포함된 문장만 골라 분석하는 방식이 아닙니다. 선택한 모든 파일의 모든 문장을 학습하므로, 예를 들어 `MZ`와 `4050`, `기성`, `청년`이 서로 비슷한 문맥에서 반복 사용되면 유사한 단어로 나타날 수 있습니다.

> Word2Vec 유사어는 사전적 동의어가 아니라, 학습 문장에서 비슷한 위치와 문맥으로 사용된 단어입니다.

## 주요 기능

- 여러 TXT 파일을 한 번에 선택해 하나의 말뭉치로 통합 학습
- Kiwi 형태소 분석을 이용한 한국어 토큰화
- 명사·영문·숫자·동사·형용사·부사 학습
- `MZ세대`, `MZ 세대`, `엠지세대` 등을 `MZ`로 통합
- 기준 키워드 여러 개 동시 분석
- 결과에서 불필요한 단어 제외
- 명사 중심 결과 또는 내용어 전체 결과 선택
- Word2Vec 유사어 결과를 `.xlsx`로 저장
- 선택적으로 학습 모델 `.model`과 PCA 그래프 `.png` 저장
- 입력 문장의 원본 파일명을 엑셀에 함께 기록
- 분석 중 GUI 멈춤을 줄이기 위한 별도 작업 스레드 사용

프로그램 파일이 있는 폴더에서 PowerShell을 열고 다음 명령을 실행합니다.


## 입력 TXT 파일 형식

TXT 파일의 **비어 있지 않은 한 줄을 하나의 학습 문장**으로 읽습니다.

```text
MZ세대는 새로운 소비 주체로 주목받고 있다.
4050세대도 온라인 소비 시장에서 영향력이 커지고 있다.
기성세대와 청년층의 정치 성향 차이를 조사했다.
```

여러 파일을 선택하면 다음처럼 모든 문장을 하나로 합쳐 학습합니다.

```text
일반뉴스_1.txt ┐
일반뉴스_2.txt ├─ 모든 문장 통합 → 형태소 분석 → Word2Vec 학습
세대관련뉴스.txt ┘
```

입력 파일은 UTF-8, UTF-8 BOM 또는 CP949 형식을 지원합니다.

### 입력 데이터 주의사항

- 제목만 넣으면 제목의 단어 관계만 학습합니다.
- 제목과 본문을 한 줄에 함께 넣으면 제목과 본문을 모두 학습합니다.
- 기사 본문이 여러 줄이면 각 줄을 별도의 학습 문장으로 처리합니다.
- 중복 문장을 자동으로 제거하지 않습니다. 동일 문장이 반복되면 해당 문맥이 더 강하게 학습됩니다.
- 기준어가 없는 일반 기사도 학습에 포함됩니다.
- 안정적인 결과를 얻으려면 기준어와 비교 대상 단어가 충분히 반복되는 대규모 데이터가 필요합니다.

### 기준 키워드 입력

기준어 하나를 분석할 때:

```text
MZ
```

여러 기준어를 동시에 분석할 때:

```text
MZ, 4050, 기성, 청년
```

각 기준어마다 설정한 유사어 개수만큼 결과가 별도로 생성됩니다.

## 표현 통합 규칙

표현 통합은 같은 대상을 가리키는 표기를 하나의 단어로 합치는 기능입니다.

규칙 형식은 다음과 같습니다.

```text
대표어=표현1|표현2|표현3; 다른대표어=표현1|표현2
```

기본 규칙은 다음과 같습니다.

```text
MZ=MZ세대|MZ 세대|엠지세대|엠지 세대|엠지;
2030=2030세대|2030 세대;
4050=4050세대|4050 세대;
기성=기성세대|기성 세대;
청년=청년세대|청년 세대;
중장년=중장년층|중장년세대|중장년 세대
```

따라서 입력 문장과 기준어는 다음처럼 처리됩니다.

```text
MZ세대   → MZ
MZ 세대  → MZ
엠지세대 → MZ
4050세대 → 4050
기성세대 → 기성
```

기준 키워드에 `MZ세대`를 입력해도 내부에서는 대표어인 `MZ`로 유사도를 계산합니다. 기사에 `MZ`만 있거나 `MZ세대`만 있어도 같은 토큰으로 학습됩니다.

새 규칙을 추가하는 예시는 다음과 같습니다.

```text
베이비붐=베이비붐세대|베이비부머|베이비 붐 세대
```

규칙 사이는 세미콜론(`;`) 또는 줄바꿈으로 구분합니다.

## 추가 사용자 단어

형태소 분석기가 한 단어를 잘못 분리할 때 직접 등록할 수 있습니다.

입력 형식:

```text
단어
단어:품사
단어:품사:점수
```

여러 단어는 쉼표로 구분합니다.

```text
갓생:NNP:5.0, 영끌:NNP:5.0, 욜로족:NNP:5.0
```

- 품사를 생략하면 `NNP`로 처리합니다.
- 점수를 생략하면 `0.0`으로 처리합니다.
- 표현 통합 규칙의 대표어와 기준 키워드는 하나의 토큰으로 유지되도록 자동 등록됩니다.

## 결과 제외어

기준어와 자주 붙지만 비교 대상이라고 보기 어려운 단어를 결과에서 제외합니다.

기본 제외어:

```text
세대, 실태, 관련, 대상, 분석, 조사, 현황
```

예를 들어 `MZ` 주변에 `세대`가 반복적으로 등장해 유사도 상위에 잡히는 것을 막고 싶다면 `세대`를 제외어로 유지합니다.

제외어 때문에 결과 개수가 부족해지면 프로그램이 더 많은 후보를 확인해 설정한 개수를 가능한 범위에서 채웁니다.

### 학습 품사

Word2Vec 학습에는 다음 품사를 사용합니다.

| 태그 | 의미 | 예시 |
|---|---|---|
| `NNG` | 일반 명사 | 소비, 문화, 세대 |
| `NNP` | 고유 명사 | 서울, 삼성, 등록한 대표어 |
| `SL` | 외국어 | MZ, AI, ESG |
| `SN` | 숫자 | 2030, 4050 |
| `VV` | 동사 | 소비하다, 증가하다 |
| `VA` | 형용사 | 새롭다, 높다 |
| `MAG` | 일반 부사 | 매우, 크게 |

조사와 어미는 학습에서 제외합니다.

### 결과 품사

`명사 중심`을 선택하면 학습에는 동사·형용사·부사도 사용하지만 최종 유사어 결과는 다음 품사로 제한합니다.

```text
NNG, NNP, SL, SN
```

`내용어 전체`를 선택하면 명사뿐 아니라 동사·형용사·부사도 결과에 포함될 수 있습니다.

### Skip-gram과 CBOW

- `Skip-gram`: 기준 단어로 주변 단어를 예측합니다. 희귀 단어의 관계를 찾는 데 상대적으로 유리하지만 학습이 더 느릴 수 있습니다.
- `CBOW`: 주변 단어로 기준 단어를 예측합니다. 학습이 빠르고 대규모 데이터에서 효율적입니다.

세대명이나 신조어처럼 등장 빈도가 상대적으로 낮은 단어를 분석할 때는 기본값인 Skip-gram을 먼저 사용하는 편이 적절합니다.

## 사용 순서

1. 프로그램을 실행합니다.
2. `기본 설정` 탭에서 `여러 파일 선택`을 누릅니다.

9. 하단 진행 로그에서 파일 읽기, 형태소 분석, 학습, 저장 상태를 확인합니다.

### Word2Vec 학습과 결과 계산 함수

| 함수 | 코드 위치 | 실행 동작 |

## 저장된 모델 다시 사용하기

`.model` 파일을 저장했다면 다른 Python 코드에서 다시 불러올 수 있습니다.

```python
from gensim.models import Word2Vec

model = Word2Vec.load("MZ_word2vec_결과.model")

for word, score in model.wv.most_similar("MZ", topn=10):
    print(word, score)
```

표현 통합 규칙은 모델에 별도 설정으로 내장되는 것이 아닙니다. 새 문장을 추가 학습하거나 다른 코드에서 기준어를 조회할 때도 동일한 대표어를 사용해야 합니다.

## 결과 해석

Word2Vec은 단어의 뜻을 사전처럼 이해하지 않습니다. 단어 주변에 어떤 단어들이 반복적으로 등장하는지를 벡터로 학습합니다.

예를 들어 다음 문장들이 충분히 많이 존재한다고 가정합니다.

```text
MZ는 새로운 소비 주체로 주목받고 있다.
4050은 주요 소비층으로 성장하고 있다.
MZ의 정치 성향을 분석했다.
4050의 정치 성향도 변화하고 있다.
기성은 자산과 주거 문제에 관심이 높다.
```

`MZ`와 `4050`이 `소비`, `정치 성향`, `주체`, `변화`처럼 비슷한 문맥에서 사용되면 두 단어의 벡터가 가까워질 수 있습니다.

반대로 `MZ` 관련 기사만 많고 `4050`이나 `기성`이 거의 등장하지 않으면 해당 단어는 유사어 상위에 나오기 어렵습니다.

## 권장 데이터 구성

원하는 비교 집단을 찾으려면 특정 키워드 기사만 넣기보다 다음 자료를 함께 학습하는 것이 좋습니다.

```text
일반 분야 뉴스
+ MZ 관련 뉴스
+ 2030·4050 관련 뉴스
+ 청년·중장년 관련 뉴스
+ 기성세대 관련 뉴스
```

단순히 파일 수가 많은 것보다 비교할 단어들이 다양한 기사에서 비슷한 문법적 위치와 주제로 사용되는지가 중요합니다.

대규모 데이터에서는 지나치게 희귀한 단어를 줄이기 위해 `최소 등장 횟수`를 5 이상으로 높여 비교해 볼 수 있습니다. 데이터가 적을 때 너무 높이면 기준어 자체가 학습 어휘에서 제외될 수 있습니다.

## 참고 및 문제 해결

### 기준어가 학습 어휘에 없다고 나오는 경우

다음 항목을 확인합니다.

- 기준어가 실제 입력 파일에 등장하는지
- 표현 통합 규칙에 의해 다른 대표어로 변환되는지
- 최소 등장 횟수보다 적게 등장하지 않았는지
- Kiwi가 기준어를 의도하지 않은 형태로 분리하는지
- 오탈자나 영문 대소문자 차이가 있는지

기준어와 표현 통합 규칙의 대표어는 자동으로 사용자 단어에 등록되지만, 입력 데이터에서 최소 등장 횟수를 충족해야 Word2Vec 어휘에 포함됩니다.

### 유사어가 기대와 다르게 나오는 경우

- 학습 문장 수가 너무 적을 수 있습니다.
- 동일 기사나 문장이 과도하게 중복됐을 수 있습니다.
- 특정 분야 기사 비중이 지나치게 높을 수 있습니다.
- 기준어가 주로 특정 단어와 붙어서만 사용됐을 수 있습니다.
- 비교 대상 단어의 등장 횟수가 부족할 수 있습니다.
- `세대`, `관련`, `분석` 같은 동반어를 제외어에 추가할 수 있습니다.

### Kiwi가 설치되지 않은 경우

프로그램은 간단한 문자열 분리 방식으로 대체할 수 있지만 한국어 조사와 어미를 정확히 구분하지 못해 분석 품질이 떨어집니다.

```powershell
.\.venv312\Scripts\python.exe -m pip install kiwipiepy
```

사용자 단어 또는 사용자 사전을 사용하려면 `kiwipiepy`가 반드시 필요합니다.

### 엑셀 저장 오류

엑셀 파일이 이미 Excel에서 열려 있으면 덮어쓰지 못할 수 있습니다. 해당 파일을 닫고 다시 실행하거나 다른 저장 파일명을 지정합니다.

### 그래프의 한글이 깨지는 경우

Windows에서는 일반적으로 `맑은 고딕`을 사용합니다. 해당 폰트를 찾지 못하면 한글 라벨이 네모로 표시될 수 있습니다.

PCA 그래프는 고차원 벡터를 2차원으로 압축한 참고용 시각화입니다. 정확한 유사도 순위는 엑셀의 코사인 유사도 값을 기준으로 확인합니다.

## 핵심 요약

이 프로그램은 다음 방식으로 작동합니다.

```text
기준어가 있는 문장만 분석하는 프로그램이 아님
→ 선택한 모든 일반 기사와 관련 기사를 함께 학습
→ 각 단어가 전체 기사에서 사용되는 문맥을 벡터로 표현
→ 기준어와 쓰임이 비슷한 단어를 검색
```

따라서 `MZ`의 유사어로 `4050`, `기성`, `청년`, `중장년` 같은 단어를 얻고 싶다면 이 단어들이 충분한 기사에서 `MZ`와 유사한 문맥으로 사용된 데이터가 필요합니다.
